# The Summit

## Purpose

Teen community space for ages 13-18 centered on life skills, belonging, creative development, and real responsibility.

## Naming Note

The final ecosystem source names this space `The Summit`. Earlier docs name the same teen concept `The Glade`. Treat The Summit as current pending founder confirmation.

## Key Details

- Judgment-free teen space with no grades, performance pressure, or social hierarchy.
- Supports neurodiverse teens through intentionally qualified staff.
- Includes communal cooking, life skills, creative arts, media production, optional core enrichment, and project work.
- Earlier weekly rhythm: Mon/Wed/Fri life skills and projects; Tue/Thu optional Layers of Learning core enrichment.
- Teen work pathways include Harvest Cafe, Sprout Space, Garden Guild, Stepping Stones mentorship, and campus projects.
