# Brand Overview

## Role

Brand owns positioning, voice, identity, naming, public language, and audience fit.

## Current State

Source language frames Cultivate as warm, grounded, inclusive, practical, family-centered, and community-built. The core tagline is `Real Skills for Real Life`.

## Current Brand Signals

- Homeschool family campus.
- Central Florida.
- Ages 0-18.
- Complete ecosystem, not a drop-off program.
- Community home from infancy through teen years.
- Inclusive of neurodiverse kids, teens, and families.
- Built with warmth, usefulness, and real-world skill.

## Naming Watch

The final ecosystem source uses `The Summit` for the teen space. Earlier source docs use `The Glade`.
