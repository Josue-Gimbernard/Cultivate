# Cultivate Domain Reports

This folder contains manager-facing domain reports for Cultivate.

## Active Starter Domains

| Domain | Files | Purpose |
|---|---|---|
| Company | `domains/company/company_overview.md`; `domains/company/company_brief.md` | Strategy, governance, operating model, source-of-truth, and cross-domain coordination |
| Product | `domains/product/product_overview.md`; `domains/product/product_brief.md` | Product/service definition, roadmap detail, user value, and delivery scope |
| Brand | `domains/brand/brand_overview.md`; `domains/brand/brand_brief.md` | Positioning, voice, identity, and public language |
| Growth | `domains/growth/growth_overview.md`; `domains/growth/growth_brief.md` | Customer acquisition, partnerships, sales, and market learning |
| Operations | `domains/operations/operations_overview.md`; `domains/operations/operations_brief.md` | Internal process, admin, finance-sensitive workflows, and execution cadence |
| Research | `domains/research/research_overview.md`; `domains/research/research_brief.md` | Market, customer, domain, and reference research |
| Spaces | `domains/spaces/spaces_overview.md`; `domains/spaces/spaces_brief.md`; individual space files | Named indoor/outdoor Cultivate spaces and their dependencies |
| Partnerships | `domains/partnerships/partnerships_overview.md`; partner files | External partnership concepts, obligations, and boundaries |
| Web | `domains/web/web_overview.md`; `domains/web/web_brief.md` | Website, private preview, UI system, UX lab, and Railway app |
