# Review Launch Viability

Use this skill when evaluating what Cultivate can responsibly launch first.

## Load First

1. `docs/normalized/cultivate_source_digest.md`
2. `domains/company/current_recommendations.md`
3. `domains/product/launch_scope.md`
4. `domains/operations/compliance_validation_map.md`
5. `domains/operations/facility_requirements.md`
6. `domains/operations/staffing_model.md`
7. `memory/10-open-questions.md`

## Review Questions

- Which source components are required for the proposed launch?
- Which components are regulated, facility-heavy, or staffing-heavy?
- Which promises would be public-facing or legally sensitive?
- What can be piloted without overcommitting?
- What must be validated with agencies, counsel, insurer, or facility experts?

## Output

Return:

- recommended launch scope
- dependencies
- blocked items
- open questions
- docs that need updates
