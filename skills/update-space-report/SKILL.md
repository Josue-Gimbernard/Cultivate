# Update Space Report

Use this skill when a Cultivate space changes or needs review.

## Steps

1. Identify the space and source docs.
2. Check `docs/extracted/` for exact wording.
3. Check `docs/normalized/cultivate_source_digest.md` for structured facts.
4. Update the relevant file in `domains/spaces/`.
5. If the change affects the whole ecosystem, update `memory/08-ecosystem-architecture.md`.
6. If the change creates launch, compliance, staffing, or facility questions, update `memory/10-open-questions.md`.
