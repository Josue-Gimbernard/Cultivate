# Coordinate Cross-Domain Priorities

Use this skill when a request affects multiple Cultivate domains.

## Steps

1. Name the domains involved.
2. Identify the source of truth for each domain.
3. Separate company-level coordination from domain-specific implementation.
4. Capture dependencies and downstream owners.
5. Update domain briefs when status changes.
6. Update memory only when the decision or rule is durable.

## Starter Domains

- Company
- Product
- Brand
- Growth
- Operations
- Research
- Spaces
- Partnerships
