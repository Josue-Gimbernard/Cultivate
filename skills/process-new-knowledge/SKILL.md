# Process New Knowledge

Use this skill when the founder provides new company facts, decisions, corrections, reference docs, or strategic context.

## Routing

- Company-wide stable context goes to `memory/03-company-context.md`.
- Safety or commitment constraints go to `memory/02-company-safety-rules.md`.
- Priority or roadmap information goes to `memory/04-roadmap-and-priorities.md`.
- Ecosystem component changes go to `memory/08-ecosystem-architecture.md` and `domains/spaces/`.
- Offers, memberships, pricing, revenue, and experience packaging go to `memory/09-offers-and-experiences.md`.
- Durable decisions go to `memory/06-recurring-decisions.md`.
- Area-specific status goes to the matching `domains/*/*` file.
- Temporary or uncertain material goes to `memory/inbox.md`.
- Exact reference docs stay in `docs/`.

## Rule

Preserve uncertainty. If something is inferred, label it as an inference.
