# Coordinate Ecosystem Dependencies

Use this skill when a change affects more than one Cultivate component.

## Steps

1. Name the affected spaces/domains.
2. Separate source-derived facts from assumptions.
3. Identify operational dependencies.
4. Identify compliance, facility, staffing, partnership, and brand implications.
5. Update domain files for area-specific changes.
6. Update `memory/08-ecosystem-architecture.md` only for durable ecosystem changes.
7. Update `memory/10-open-questions.md` for unresolved dependencies.

## Common Dependency Paths

- The Summit -> Harvest Cafe teen work experience.
- The Summit -> Sprout Space teen childcare work.
- The Summit -> Stepping Stones mentorship.
- The Summit -> Wilds sign/build projects and Canopy use.
- Growing Grounds -> Harvest Cafe and communal meals.
- Commons -> Harvest Cafe catering.
- Grove -> parent contribution and community depth.
- Foxtail -> Harvest Cafe operations, brand, and teen training.
