# Cultivate Company

Company operations, strategy, governance, cross-domain coordination, and durable agent memory for Cultivate.

This repo is the markdown source of truth for how we work on the company. It is intentionally lightweight at the start: capture the basics, make decisions durable, and expand only when the company needs the extra structure.

## Start Here

For any new Codex/company session, read:

1. `AGENTS.md`
2. `COMPANY_AGENT_PROTOCOL.md`
3. `memory/00-index.md`
4. The smallest relevant files under `memory/`, `domains/`, or `skills/`

For current buildout work, start with:

- `docs/normalized/cultivate_source_digest.md`
- `domains/company/current_recommendations.md`
- `domains/company/buildout_roadmap.md`
- `domains/product/launch_scope.md`
- `domains/product/founding_cohort_launch_plan.md`
- `domains/operations/compliance_validation_map.md`
